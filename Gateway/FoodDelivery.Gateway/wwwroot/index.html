Quick Start Guide

1. Login as Admin:

• Open Auth Service Swagger

• Use POST /api/auth/login

• Email: admin@fooddelivery.com | Password: Admin@1234

2. Authorize:

• Copy the accessToken from login response

• Click Authorize button in any Swagger UI

• Enter: Bearer {your-token}

3. Test Endpoints:

• All protected endpoints are now accessible

• Gateway routes all requests through http://localhost:5000/gateway/*

• Direct service access available for development
